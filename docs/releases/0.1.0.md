# FF8Recomp 0.1.0

The first public build: FINAL FANTASY VIII (the 2013 Steam release) recompiled to native ARM64
Android, built on your device from your own copy. The APK contains no game code or data.

## What works
- Import your game folder (`steamapps/common/FINAL FANTASY VIII`: `FF8_EN.exe` + `Data`) or
  download it from Steam with your account; the launcher builds the game for your device once.
- The game: title screen, opening movie, fields, the world map, menus and battles (tested on an
  AYN Thor), with its music played by FF8Recomp's own DirectMusic player and the game's own
  instruments (`FF8.dls`).
- Your PC saves (`slot1_save01.ff8`…) under `Android/data/com.ff8recomp/files/game/save/user_0/`.
- Save states (Select+L1 / Select+R1), 16:9, Vulkan or OpenGL ES, controller, keyboard and touch
  controls.

## Not yet
- The Remastered edition.

- DirectMusic's reverb and chorus.

## Install
Download `FF8Recomp-0.1.0.apk` below and install it, then follow **Game files** in the launcher.
See the [README](../../README.md) for details.

This project was built with AI (see the README's "Made with AI"). Please report problems with
**Report a problem** in the launcher.
