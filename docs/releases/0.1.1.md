# FF8Recomp 0.1.1

**Fixed: the Remastered could crash as soon as it started on some devices** (#4).

The Remastered's program leaves out one call that FFNx looks for at start-up. FF8Recomp followed it
anyway and read a meaningless address. On some devices nothing is there to read, and the game closed
before it began, with or without mods. It now uses the Remastered's own call instead. The 2013
release is not affected.

Not in this release: the other start-up crash, where Play goes back to the launcher and the log says
"game memory moved" (#2). It happens with both editions, and a phone that had the crash above may
still have that one. It is being worked on.

### Updating
Install `FF8Recomp-0.1.1.apk` over 0.1.0 (the launcher also offers it). If it asks, press **Update
the game**: it links the game you already built with the new engine, which takes a few seconds and
is not a new build. Your saves, mods and settings stay.
