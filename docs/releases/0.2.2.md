# FF8Recomp 0.2.2

**Fixed: the game closed when mods put textures of different sizes side by side** (reported in #8 with
Lunar Cry Plus in battles and Horizon Pack Plus in towns), in either edition.

The game keeps several textures on one page. When a mod's textures on a page were enlarged by different
amounts and one size was not a whole multiple of the other, the smaller one was read past its end, and
the game closed. The same mistake could also draw such textures slightly wrong. Textures are now
always read inside their own picture.

This was tested on an AYN Thor with the Remastered: test textures that closed 0.2.1 at the same place
in the program as in the report no longer do, and a battle without mods still looks right. It was not
tested with the two mods themselves.

### Updating
Install `FF8Recomp-0.2.2.apk` over 0.2.1 (the launcher also offers it), then press **Update the game**
when the launcher asks (a few seconds; from an older version it can take longer) and Play. Your saves,
mods and settings stay. Save states made with earlier versions may not load (not tested).
