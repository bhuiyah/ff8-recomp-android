# FF8Recomp 0.2.1

**Fixed: Home left the panels on the second screen** (#12), in either edition.

Pressing Home sent the game away on the top screen, but the second screen's panels stayed there until
the game was closed. They now leave the second screen whenever the game goes to the background, and
come back when you return to it.

This was tested on an AYN Thor: Home and back, and the device put to sleep and woken. It does not
change **Swap screens** (Settings > Screen), where the panels are on the main display.

### Updating
Install `FF8Recomp-0.2.1.apk` over 0.2.0 (the launcher also offers it), then press Play. From 0.2.0
the game does not have to be built again; from an older version, press **Build for this device** if it
asks. Your saves, mods and settings stay.
