# FF8Recomp 0.2.4

**Save-state buttons can be changed** (#14): Settings > Controller has **Save state** and **Load state**,
where you pick A, B, X, Y, L1, R1, L2, R2 or none (pressed with Select), and **Swap save and load**. The
defaults are still L1 to save and R1 to load.

**More Demaster mods** (#13): textures from a `DEMASTER_EXP` folder that replace whole pages now load, as
`.png` or `.dds`:
- field backgrounds (`field_bg`)
- battle stages (`battle.fs/hd_new/a0stg...`); animated ones show only their first frame
- the world map (`world/dat/texl` and `wmset`)
- `.dds` files in place of the Remastered's own textures

Not supported: the minimap (`wmset0`), textures matched by fingerprint (`hashOutput`), and mods that
patch or replace Demaster's or the game's DLLs.

Tested on an AYN Thor with the Remastered, using test textures in Demaster's layout (the world map, one
battle, one field). Not tested: real Demaster mods, `.dds` files in place of the Remastered's own
textures, and the 2013 release.

### Updating
Install `FF8Recomp-0.2.4.apk` over 0.2.3 (the launcher also offers it), then press **Update the game**
when the launcher asks (a few seconds; from an older version it can take longer) and Play. Your saves,
mods and settings stay. Save states made with earlier versions may not load (not tested).
