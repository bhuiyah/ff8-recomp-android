# FF8Recomp 0.1.2

**A fix for Play going back to the launcher on Android 16** (#2), with both editions.

Android 16 keeps its own memory at an address where part of FINAL FANTASY VIII's program has always
lived. As the game started, the two overwrote each other and the app closed. That part of the game
now lives somewhere else, and every place in the program that refers to it was changed to match.

We do not have an Android 16 device. This was tested on an Android 13 device with that range of
memory blocked, so anything still using the old place would have crashed. If Play still goes back to
the launcher for you, please comment on #2 with a Report a problem zip: the log now says what is in
the way.

### Updating
Install `FF8Recomp-0.1.2.apk` over the version you have (the launcher also offers it).

- **The game has to be built again once** (press **Build for this device**; as long as the first time).
- **Save states made with earlier versions do not load.** The game's own saves are not affected, and
  your mods and settings stay. If you only have a save state somewhere, load it in the version you
  have and save at a save point before updating.

Later updates should be much quicker: from this version on, a build keeps what it compiled, and an
update compiles only the parts of the game it changes. On our test device an update that changed
none of the compiled parts took 3 minutes; a full build takes over 14. The build also tries a file
again if the compiler stops on it.
